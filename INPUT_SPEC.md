# Input Specification — CpG-centric cis-mQTL Prioritisation Framework

This framework prioritises candidate cis-acting methylation-controlling variants.
It is CpG-centric: CpGs are the molecular phenotype; variants are mapped to CpGs,
fine-mapped, annotated (SV, functional, ASM), and collapsed to variant level.

To apply the framework to a new dataset, provide the following inputs.

## 1. Methylation matrix (per chromosome)
BED-like, bgzipped + tabix-indexed. Columns:
  #chr, start, end, phenotype_id, then one column per sample (M-values).
  phenotype_id format: chrN_pos (encodes CpG position).
  Path pattern: matrix/{cohort}/chrN.methylation_Mval.bed.gz

## 2. Genotypes (per chromosome, PLINK)
  chrN.samples.{bed,bim,fam}. Variant IDs: chr:pos:ref:alt (build must match matrix).
  In-sample genotypes (LD computed in-sample for fine-mapping).

## 3. Covariates (per chromosome)
  TSV: rows = covariates, columns = samples. Include technical (platform, basecaller)
  and PCs (genotype PCs + methylation PCs). Sample order matches matrix/genotypes.

## 4. Sample list
  config/keep_geno.txt: one sample ID per line (unrelated founders recommended).

## 5. Reference annotation (for functional stage)
  - GENCODE GTF (gene TSS), UCSC CpG islands, ENCODE cCRE BED (4-col: chrom,start,end,class).
  - Reference genome FASTA (+ .fai) matching the build.

## 6. Structural variants (optional, for SV integration)
  Panel VCF with SVs (SVTYPE INFO or symbolic ALT). Per-chromosome.

## 7. Haplotype methylation (optional, for ASM)
  Per-sample hp1/hp2 bedmethyl (e.g. modkit --phased pileups), tabix-indexed.
  manifest: sample_id -> hp1_url, hp2_url.

## 8. GWAS summary statistics (optional, for colocalization)
  Per-variant: chr, pos, effect allele, other allele, beta, SE, allele freq, N.
  Build noted; framework lifts mQTL build to GWAS build (pyliftover).

## Outputs (per stage)
  - Discovery: significant_cpgs (FDR<0.05), per-CpG permutation results
  - Fine-mapping: per-CpG SuSiE PIP + credible sets
  - SV: per-CpG SV-implication flags
  - Functional: per-CpG nearest gene, cCRE, CpG island
  - Prioritisation: variant-level ranked table (score_weighted, score_convergence)
  - ASM: per-region haplotype ASM (MWU + Fisher), aggregated across samples
  - Final: enriched variant table with all evidence + ASM, imprinting flagged

## Key parameters (defaults)
  cis-window: +/-1 Mb | MAF threshold: 0.05 | FDR: Benjamini-Hochberg
  Permutations: 100 | SuSiE L: 10 | SV: assoc p<1e-3 AND r2>0.8 with lead
  ASM: per-CpG MWU on haplotype rates + pooled Fisher; min coverage 5, min CpG 3
  Coloc: coloc.abf, priors p1=p2=1e-4, p12=1e-5

## Reproducibility scope (honest)
  - All code, parameters, and environment (environment/mqtl_tensorqtl.yml) are versioned.
  - Demonstrated on the PUBLIC 1000G-ONT resource (lymphoblastoid cell lines).
  - Pipeline is a documented multi-stage workflow (see RUN_ORDER_NCI.md), run on NCI Gadi.
  - Scripts contain cohort/system-specific paths; adapting to a new dataset requires
    editing paths + providing the inputs above. The METHODOLOGY is transferable;
    it is not a turnkey tool for arbitrary data.
  - Heavy intermediates (nominal parquets ~205GB, pileups) are regenerated by the
    scripts from public data, not committed.
  - NCI note: compute nodes lack internet; external downloads use the copyq queue.
